# Compound List 完整重设计

**日期:** 2026-06-19
**范围:** `templates/compound_list.html`, `app01/views.py` (`compound_list` view), 可能涉及 `app01/models.py` 结构调整

---

## 背景与目标

当前 `/compounds/` 页面存在三个核心问题：

1. **体内数据分散展示**：每个剂量组是独立的一行，无法在同一张图上看到剂量-反应关系
2. **给药方案混淆**：Q2W×3 和 QW×5 的数据混在一起，观察期不同导致视觉误判
3. **时间点缺失**：体重数据仅展示7的倍数天，丢失给药后早期动态

目标：以批次为主轴重新组织页面，体内数据按给药方案分图展示，完整展示所有时间点。

---

## 设计决策汇总

| 问题 | 决策 |
|------|------|
| 主轴 | **批次为主**（纯批次模式，去掉"按化合物"切换） |
| 同批次混合类型 | 批次内**按类型分子区块**（体外子区 + 体内子区，各自独立表头） |
| 体内多给药方案 | **按给药方案拆分子图**（Q2W×3 一张图，QW×5 一张图），Saline 作参考线出现在两张图中 |
| 体内多指标 | **Readout tabs**（体重% / KD% / 其他），单指标时 tab 不出现 |
| 时间点 | 图表显示**全部时间点**（每日），摘要表只列关键时间点 |
| 序列展示 | 折叠行：仅 AS；展开：AS + SS 彩色 token 对齐 |
| 源文件 | 每个展开面板底部，**可下载 + 内联预览**（横向滚动） |

## 子区块（混合批次内部）

混合批次内部按类型分两个子区块，各有独立分隔 header：

```
🔬 体外  |  细胞系: HepG2 · 转染: RNAiMAX · 2个化合物
─────── 体外表格（见下）────────────────────────────────

🐭 体内  |  动物: 雌性 C57BL/6 · 给药: 皮下注射 · 指标: 体重% · 1个化合物
─────── 体内表格（见下）────────────────────────────────
```

纯体外/纯体内批次不显示子区块 header，直接进表格。

## 关键时间点选取规则（摘要表）

- **体重**: Day 0（基线）、Day 7、Day 14（如存在）、最大降幅日、末次观测日
- **KD%**: Day 7、各给药后关键采样日、末次采样日
- 若总天数 ≤ 14，显示全部时间点

## Backend 数据结构变更

### `compound_list` view 返回结构

当前：`row_data` 是扁平列表（每条 = 化合物 × 实验）

新结构：
```python
batch_groups = [
    {
        'batch_label': 'T1',
        'date': ...,
        'type': 'in_vitro',   # 'in_vitro' | 'in_vivo' | 'mixed'
        'meta': {...},         # 批次级别元数据
        'vitro_compounds': [   # 仅 type != 'in_vivo' 时有
            {
                'compound': Compound,
                'experiment': Experiment,
                'ic50_str': '0.8',
                'max_kd_pct': 78,
                'vitro_rows': [...],        # 剂量点数据
                'colored_as': [...],        # 彩色 token list
                'colored_ss': [...],
                'attachments': [...],
            }
        ],
        'vivo_compounds': [    # 仅 type != 'in_vitro' 时有
            {
                'compound': Compound,
                'schedules': {             # 按给药方案分组
                    'Q2W×3': {
                        'days': [...],
                        'groups': [{'label': '3mpk', 'data': [...]}, ...],
                        'control': {'label': 'Saline', 'data': [...]},
                    },
                    'QW×5': {...},
                },
                'readouts': ['body_weight', 'knockdown_pct'],
                'summary': {'max_bw_drop': -20.2, 'peak_kd': 87},
                'colored_as': [...],
                'colored_ss': [...],
                'attachments': [...],
            }
        ],
    },
    ...
]
```

### 分页单位
按批次分页：每页显示 N 个 `batch_groups`（默认 10 个批次）。

## 体内数据解析修正

当前 `prism_upload.py` 解析体重数据时仅取7的倍数时间点，需修改为：
- 保留全部时间点（CSV 中每一行 = 每一天）
- 列 header 中的 `schedule` 信息（如 `Q2W*3`、`QW*5`）存入 `DataPoint` 的 `schedule` 字段或 `Experiment.dose_info`
- 同一批次同一化合物的不同给药方案组，在 view 层按 `schedule` 聚合为 `schedules` dict
